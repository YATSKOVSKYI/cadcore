# Changelog

## 0.1.23

Licensing and packaging release based on 0.1.22. Rust source code is unchanged.

- Declare MIT consistently for all six published cadcore crates.
- Include the full MIT LICENSE in every published crate archive.
- Include the copyright holder's additional MIT grant for earlier releases.
- Clarify the historical PolyForm metadata on each crate's README page.
- Require 0.1.23 or newer for all internal cadcore dependencies.

This release does not include the unreleased geometry changes on master or
`cadcore-union`. It does not fix STEP serializer issue #2. Existing crates.io
archives and their historical license metadata remain unchanged.
